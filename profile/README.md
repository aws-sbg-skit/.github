# AWS Student Builder Group — SKIT Jaipur ☁️🚀

Welcome to the official GitHub organization of the **AWS Student Builder Group (SBG)** at **Swami Keshvanand Institute of Technology, Management & Gramothan (SKIT), Jaipur**.

We are a student-led developer community dedicated to empowering young builders with hands-on cloud skills, AI/ML exploration, real-world architecture design, and official AWS certifications.

---

### 🌟 What We Do
* **Hands-on Cloud Labs & Workshops:** Guided walkthroughs covering core AWS compute, serverless, storage, and generative AI services.
* **Competitions & Cloud Quests:** Interactive role-playing tournaments, gamified sandboxes, and hackathons.
* **Certification Enablement:** Prep cohorts, study roadmaps, and support for AWS Cloud & AI Practitioner certifications.
* **Community Initiatives:** Watch parties, tech meetups, and ecosystem collaborations with AWS User Groups across Rajasthan.
